# Who said that?
> made at Hack Club Macondo 

This project was made by Luciana Montaña and Salma Mebarak ('The amazing chimba duo') for Hack Club Macondo.

This is an interactive website that we made to simulate the viral trivia question: 'who said that quote, Kanye or Trump?'. This is a debate that has been going on on the internet for a while now (people guessing if a controversial quote was made by Kanye or Trump), but we wanted to adapt it to Colombia's context. We'll show you a a concerning quote, and you'll have to guess if it was said by a colombian politician or a reggaeton artist. To confuse the user, we choose the most 'woke' or political phrases from reggaeton artists, and the most controversial/informal ones for the actual politicians. It is not yet adaptable for other web devices, which we think is the main challenge that we faced while building this project. Since this was one of your first web pages, we didn't know how to make it adaptable for devices that were not our computers, and we noticed it way too late, so we haven't got time to fix it. After the hackaton, though, we'll be working on making it adaptable, and most likely addinig more details (like politicians memes) that we didn't got time to add. Another thing that was difficult for us, was getting information of of a Javascript array and being able to use the information prolery. We finished with a pretty simple (and flawed) demo, but we're pretty proud of how it turned out.
